Tag and reshape heap text streams with deterministic transforms. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/tagheap.git
cd tagheap
node src/cli.js --help
node --test
