# tagheap

Tag and reshape heap text streams with deterministic transforms.

**Site:** https://theworker02.github.io/tagheap/

## Install / run

```bash
git clone https://github.com/theworker02/tagheap.git
cd tagheap
node src/cli.js
node --test
```
